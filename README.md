# نارون | Narvan (Elm) — فروشگاه لوازم تحریر

فروشگاه فارسی RTL با HTML/CSS/JavaScript خالص؛ مناسب GitHub Pages و Cloudflare Pages، بدون نیاز به build.

## شروع سریع
فایل‌ها را در ریشهٔ مخزن قرار دهید و Pages را روی شاخهٔ اصلی و پوشهٔ `/` تنظیم کنید. این نسخه برای نمایش و تست فرانت‌اند است.

## امکانات این نسخه
- هویت بصری سبز الهام‌گرفته از درخت نارون (Elm)، چیدمان واکنش‌گرا و انیمیشن‌های سبک.
- صفحهٔ تنظیمات: حالت جمع‌وجور، روشن/خاموش‌کردن انیمیشن و پاک‌سازی داده‌های محلی.
- فروشگاه، جست‌وجو، دسته‌بندی، سبد خرید، کوپن، محاسبهٔ ارسال، سفارش نمایشی و پرداخت آزمایشی.
- متادیتای فارسی، Open Graph، JSON-LD، robots.txt، manifest و سربرگ‌های امنیتی پایه برای Pages.
- اعتبارسنجی فرم و escape کردن مقادیر ذخیره‌شده هنگام نمایش فرم گیرنده.

## محدودیت‌های مهم
این نسخه **پایگاه داده یا سرور ندارد**؛ داده‌ها فقط در localStorage مرورگر ذخیره می‌شوند و قابل اتکا برای فروش واقعی نیستند. پرداخت فعلی شبیه‌سازی است و پولی جابه‌جا نمی‌کند. شماره شبا به‌تنهایی درگاه بانکی نیست؛ اتصال واقعی نیازمند API سروری و درگاه معتبر است. برای جلوگیری از انتشار اطلاعات مالی، شماره شبای ارائه‌شده در کد و صفحات عمومی قرار داده نشده است.

محصولات و قیمت‌ها در `products.js` نمونه‌اند. تصاویر محصول در نسخهٔ اولیه تصاویر برداری جایگزین‌اند؛ در محیط ساخت این نسخه دسترسی شبکه برای دانلود عکس‌های دارای مجوز فراهم نبود، بنابراین عکس دانلودشدهٔ واقعی به آرشیو اضافه نشده است. جایگزین‌کردن تصاویر در `images/p{id}.jpg` پشتیبانی می‌شود.

## پیش از انتشار واقعی
مطالعهٔ `SECURITY.md` ضروری است. تلفن/ایمیل/نشانی و سیاست‌های واقعی را تعریف کنید، محصولات و قیمت‌ها را تأیید کنید و پیش از دریافت پول، بک‌اند، دیتابیس، احراز تراکنش سمت سرور و آزمون امنیتی راه‌اندازی شود.

## سئو
عبارت‌های اصلی شامل لوازم تحریر، لوازم التحریر، نوشت‌افزار، نارون، خودکار، مداد، کتاب، دفتر، مدادرنگی و ماژیک هستند. محتوای مفید و منحصربه‌فرد محصول، قیمت و موجودی واقعی، دامنهٔ نهایی و Search Console نیز برای سئوی واقعی لازم‌اند.
