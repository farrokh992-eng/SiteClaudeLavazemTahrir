# نارون — فروشگاه آنلاین لوازم تحریر

سایت استاتیک (HTML/CSS/JS خالص) با هویت بصری انار (عنابی، طلایی، سبز برگ). طراحی جدا برای موبایل و دسکتاپ.

## اجرا روی GitHub Pages
۱. فایل‌ها را در یک مخزن آپلود کنید. ۲. Settings ← Pages ← شاخهٔ main، پوشهٔ root. ۳. آدرس: `USERNAME.github.io/REPO`

## پیش از انتشار حتماً ویرایش کنید
- `app.js` ← ثابت `SITE`: تلفن، ایمیل، نشانی و ساعت کاری (الان نمونه است).
- `products.js`: قیمت‌ها، موجودی و برند (برند همه «نارون» نمونه است).
- عکس واقعی: `images/p1.jpg` تا `p12.jpg` (در غیر این صورت تصویر گرافیکی نمایش داده می‌شود).

## پرداخت آزمایشی
کارت پیش‌فرض موفق؛ کارت منتهی به `0000` یا «انصراف» ناموفق. کد تخفیف: `NOTE20`، `WELCOME10`.
برای پرداخت واقعی باید به درگاه بانکی از طریق یک سرور وصل شود (تابع `gateway()`).

## صفحات
خانه، فروشگاه، محصول، سبد، ارسال و پرداخت، سفارش‌ها، دربارهٔ ما، ارسال و هزینه، شرایط بازگشت، پرسش‌های متداول، تماس.
