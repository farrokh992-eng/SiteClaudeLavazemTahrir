# خط‌کش — فروشگاه آنلاین لوازم تحریر

سایت استاتیک (HTML/CSS/JS خالص) بدون نیاز به نصب یا بک‌اند.

## امکانات
- صفحهٔ اصلی، فروشگاه با جست‌وجو، فیلتر دسته‌بندی و مرتب‌سازی
- صفحهٔ محصول، سبد خرید (ذخیره در مرورگر)، کد تخفیف (`NOTE20`، `WELCOME10`)
- ارسال رایگان بالای ۵۰۰ هزار تومان، ثبت سفارش با اعتبارسنجی فرم، کد پیگیری و صفحهٔ سفارش‌ها
- طراحی ریسپانسیو و راست‌به‌چپ

## اجرا روی GitHub Pages
1. یک مخزن (Repository) جدید بسازید و همهٔ فایل‌های این پوشه را آپلود کنید.
2. Settings ← Pages ← Source: `Deploy from a branch` ← شاخهٔ `main` و پوشهٔ `/ (root)`.
3. بعد از چند دقیقه سایت در `https://USERNAME.github.io/REPO/` فعال می‌شود.

اجرای محلی: فایل `index.html` را در مرورگر باز کنید.

## شخصی‌سازی
- محصولات: `products.js`
- رنگ‌ها: متغیرهای ابتدای `style.css`
- کدهای تخفیف و هزینه ارسال: ابتدای `app.js`

## نکته
پرداخت و ارسال شبیه‌سازی است. برای فروش واقعی باید به درگاه پرداخت و سرور متصل شود.
