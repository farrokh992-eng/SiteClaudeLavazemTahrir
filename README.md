# خط‌کش — فروشگاه آنلاین لوازم تحریر

سایت استاتیک (HTML/CSS/JS خالص) بدون بک‌اند. طراحی جداگانه برای موبایل (نوار پایین، ۲ ستون، نوار خرید ثابت) و دسکتاپ (جست‌وجوی هدر، فیلتر کناری، ۴ ستون).

## جریان خرید
محصولات ← سبد ← اطلاعات ارسال (استان/شهر/کد پستی/روش ارسال با زمان تحویل) ← پرداخت ← تأیید و پیگیری.
درگاه پرداخت **آزمایشی** است: کارت پیش‌فرض موفق؛ کارت منتهی به `0000` یا دکمهٔ «انصراف» ناموفق. کد تخفیف: `NOTE20`، `WELCOME10`.

## اجرا روی GitHub Pages
۱. فایل‌ها را در یک مخزن آپلود کنید. ۲. Settings ← Pages ← شاخهٔ main، پوشهٔ root. ۳. آدرس `USERNAME.github.io/REPO`.

## عکس واقعی
عکس‌ها را با نام `p1.jpg` تا `p12.jpg` در پوشهٔ `images/` بگذارید؛ به‌صورت خودکار نمایش داده می‌شوند.

## شخصی‌سازی
محصولات و قیمت‌ها: `products.js` · روش‌های ارسال و کد تخفیف: ابتدای `app.js` · رنگ‌ها: ابتدای `style.css`

## وصل کردن درگاه واقعی
تابع `gateway()` در `app.js` را با ریدایرکت به درگاه (زرین‌پال، IDPay، …) از طریق یک سرور جایگزین کنید؛ بدون سرور، پرداخت واقعی امن نیست.
